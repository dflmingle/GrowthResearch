# 发布范围

本仓库来自独立导出，不移动、不修改原始工作区。

## 已发布

- 全部00—78报告及根目录汇总结果，保持原编号、文件名与字节；00—67原报告不改写。
- 自编分析/采集脚本、主证据图、证据索引、主张矩阵、来源台账及汇总实验结果。
- 能通过既有原始SHA256和官方来源URL核验的SDK原包、POM、公开源码JAR及Unity包许可证。
- 研究者生成的合成离线结果，与真实公开UCI实验分别标注。
- 后续MVP、LTV lab、E01/E02及能力收敛的源码、schema、fixture、合成数据库、模型参数、实际日志和失败记录；这些不是玩家身份或真实游戏收入。
- 官方样本许可审计与Adjust三版本MIT源码/差分。审计中的47份样本均已在原282份SDK发行文件中，哈希相同，未重复下载或增加许可未核实的SDK。

## 本地保留

- 游戏APK/XAPK、完整游戏反编译/资源树、引擎工具可执行文件。
- 逐客户交易、广告机会原始样本和所有下载数据集。
- 网页/响应/素材缓存、重复SDK反编译树、机器缓存及普通采集日志；合成工程验收所需日志单独保留。
- 历史证据图和索引的重复备份；当前主图及原证据位置、哈希保留。

## 文件清单

- [ORIGINAL_FILE_MANIFEST.csv](ORIGINAL_FILE_MANIFEST.csv)：逐字节复制的工作区文件，包含SDK原包。
- [SDK_ARTIFACTS.csv](SDK_ARTIFACTS.csv)：本次实际入库的SDK、来源与许可字段。
- LOCAL_REFERENCE_GAPS.csv：历史Markdown里未随本次发布的本地引用或机器绝对路径。属于可用性缺口，不是新增证据。
- VALIDATION.json：发布包结构与哈希验证，不是生产系统或模型认证。
- CURRENT_SCOPE.json、SYNC_RESULT.json、WORKSPACE_PRESERVATION.json：本次增量范围、复制清单和原工作区保护结果。

报告中的源码位置与哈希保留历史语义，并非每个引用都能在GitHub点击。利用SDK发行包、代码证据目录与来源URL核验；不以空文件或伪造链接替代未发布原件。

历史保全脚本可能依赖未发布的缓存、原数据或机器路径。裁剪仓库不伪造这些原件，也不放宽原STOP；发布核验与完整研究环境重放是两种检查，见[复现边界](../REPRODUCING.md)。
