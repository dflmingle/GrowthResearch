## SDK releases

Official releases remain byte-for-byte reference artifacts. [SDK_ARTIFACTS.csv](publication/SDK_ARTIFACTS.csv) records vendor, version, SHA256, upstream URL and declared license or pointer. POMs and available packaged notices are preserved. A public download URL is not a statement of unrestricted use or redistribution rights.

AppLovin SDK EULA, Unity terms/Companion Package License, Google/Meta/TikTok SDK terms and other vendor-specific conditions continue to apply. Review the exact upstream terms before use, modification or redistribution. A sources JAR may contain only public API stubs; it does not establish that the full SDK is open source.

## Documents and evidence

The later official-samples-audit documents version-specific permission gates and corrections. In particular, a 404 response once labeled as an AppLovin adapter license is not a valid license. The limited Adjust 5.5.0 / 5.7.0 / 5.8.1 source extracts and diffs in adjust-mechanisms retain the original MIT LICENSE files and attribution. This permission does not extend to MAX, LevelPlay, or other dependencies.

Excerpts and source catalogs are retained for technical analysis and attribution. Original publishers retain their rights. Complete web caches and advertising creative media are not mirrored.
