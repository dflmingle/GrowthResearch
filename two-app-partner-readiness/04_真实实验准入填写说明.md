# GO/HOLD/STOP判定填写说明

填写[RA00—RA11判定表](04_真实实验准入判定表.csv)，汇总到[准入结论模板](04_准入结论填写模板.json)。本轮**未收到任何合作方材料**；默认真实实验STOP，所有证据与签认留待填，不把生成模板当执行过的检查器。

合作方先填`partner_answer`（YES/PARTIAL/NO/UNKNOWN）、文档别名和适用范围，不附真实行或原始后台链接。指定复核人核对原件/语义后，才填`verification_status`、结论、缺口、责任角色和有效期。文件名存在、字段齐全、自报“是”、高匹配分数或SHA256正确，都不足以证明真实授权和事实。

## 规则

1. **GO必须范围化**。资料评审GO仅允许元数据评审；受控查验GO不等于训练GO。图谱真实实验须全部适用RA00—RA11通过，合法处理/关系用途/标签成熟明确，且完成方法、安全、权利审批及新执行任务授权；本表从不自动启动操作。
2. **HOLD表示待证，不表示可以先训练**。例如质量真值、时钟、水位、功效或环境未确认时，先补对应证明，实际执行仍STOP。
3. **STOP硬门**：没有明确授权，或没有合法跨App关系依据，或没有成熟标签，整体真实图谱实验必须STOP。明确越权、泄漏、经济重复或粒度错误也必须停止；记录原因，不推断对方一定违法或没有能力。
4. **N/A要有理由与有权签认**。IAP-only可以不要求IAA，但不能仍称总收入；RA00授权、RA06合法关系、RA08标签成熟不能整门N/A。改成同App研究须另定任务，不能用不适用绕过本题。

|verification_status|含义|gate_decision|
|---|---|---|
|UNKNOWN|尚无证据或未完成复核|HOLD；硬门未满足时STOP|
|VERIFIED_PASS|在列明范围内证据通过，并有签认/有效期|GO_SCOPED，仅该门|
|VERIFIED_FAIL|有明确不满足/矛盾|STOP，记录事实和修复路径|
|SIGNED_NA|确实不适用且有权审核人签认|仅允许已批准的局部不适用|

整体判定伪规则：

```text
如果RA00未验证明确处理授权 → STOP_AUTHORIZATION，禁止行数据导入
如果RA06缺合法关系依据 → STOP_RELATION_USE，禁止图谱特征实验
如果RA08无成熟标签证明 → STOP_IMMATURE_LABELS
如果任一明确失败 → STOP，并保留各门子事实
否则如有未知/待补/未冻结或未指定责任 → HOLD，执行STOP
否则由有权批准人签认限定任务/环境/时段/输出/有效期 → GO_SCOPED
即使GO_SCOPED，也不自动启动真实读取、训练或任何生产接口
```

问卷和schema只用于首轮元数据尽调。下一阶段真实原件查验应由获准人员在合作方环境进行，研究方可以仅获得可引用的范围化审计与聚合结果。供应方声明与独立核验分别标记；模型读取、关系质量、预测增益和Axon/Vector生产消费不能相互代替。
