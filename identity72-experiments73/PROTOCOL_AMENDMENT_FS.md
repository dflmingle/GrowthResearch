# 预注册补充B-FS：明确的概率匹配基线

目的：原B协议的固定相似度均分不是概率生成模型，不能将其冒称概率匹配。保留原实验和结果，新增独立固定Fellegi-Sunter式条件独立基线，补齐任务方法覆盖。不根据原测试成绩选择特征、参数或阈值。

执行前固定：沿用B原档案隔离split和5个字段；每字段状态为缺失、非缺失且不相似、相似度[.5,.8)、[.8,1)、非空精确交集；训练集分别估计match/nonmatch状态概率，Laplace平滑alpha=1，乘独立似然比并合并训练prior得到后验分数。仅验证集选择最大F1阈值，测试集不调参。该条件独立假设不保证后验校准，不以真实生产匹配概率解释。

沿用缺失/扰动场景及200次档案分量bootstrap，报告相同指标。原B图基线的候选图只有孤立档案对，闭包不能产生新增多跳证据；保留这个限制，不虚构完整簇真值。
